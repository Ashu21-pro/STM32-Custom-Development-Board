# STM32 Custom Development Board — KiCad PCB Design

## Overview
This repository contains the schematic and PCB layout for a custom STM32-based development board designed in KiCad. The design includes a microcontroller circuit, power-supply circuitry, decoupling components, and UART and SWD connectors.

## Features
- STM32 microcontroller-based design
- On-board power-supply circuitry
- UART connector for serial communication
- SWD connector for programming and debugging
- Routed PCB layout
- Four mounting holes
- 3D PCB visualization

## Tools Used
- KiCad Schematic Editor
- KiCad PCB Editor
- KiCad 3D Viewer
